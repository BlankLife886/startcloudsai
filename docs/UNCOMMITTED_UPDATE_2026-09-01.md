## 3. AI 助手

### 3.1 同一对话多任务排队

- 同一对话允许一条任务运行时继续发送后续消息。
- 每个对话最多排队 `10` 个任务，每个用户最多排队 `20` 个助手任务。
- 队列按照 `queue_position`、创建时间和 ID 稳定排序，同一对话同一时间只运行一个任务。
- 排队消息可编辑、取消、上移和下移；任务开始后不能继续编辑或调整顺序。
- Worker 重启、租约过期或队列投递短暂失败时，可从数据库 outbox 恢复，不依赖浏览器一直打开。
- 前端显示当前任务和排队位置，避免用户误以为连续发送的需求丢失。

### 3.2 运行状态和取消语义

- 助手运行记录保留真实 `status`、`stage`、排队位置、尝试次数、冻结积分、实际结算和失败原因。
- 用户端不再展示冗长的“四阶段流程条”；只保留对当前状态有帮助的简洁反馈。
- 取消排队任务：立即取消，并释放未发生的费用。
- 取消已经提交上游的图片任务：必须明确确认；只停止本站等待和接收结果，上游可能仍继续生成，已发生的调用不会伪装成可退款。
- 页面刷新后从服务端恢复状态，流式连接断开也不会把任务永久留在“处理中”。

### 3.3 图片创作方案

- 助手可先生成图片方案，再由用户确认执行，而不是把模糊需求直接提交生图。
- 支持“忠实模式”和“增强模式”：忠实模式尽量保留原始约束，增强模式允许补足构图、光线和表现细节。
- 多张图片可形成逐张独立方案，避免所有输出机械复用同一个提示词。
- 参考图进入方案上下文，方案会记录参考图、用途、模型能力和输出数量。
- 在执行前校验模型是否支持参考图、编辑、数量、比例和分辨率，减少提交后才发现参数不支持。

### 3.4 联网搜索和来源

- `web_search` 支持公开网络检索、有限重试和来源链接。
- 是否可联网由所选服务商/线路能力决定，不再额外要求用户选择“搜索模型”。
- 搜索结果作为工具结果进入对话，页面保留可点击引用，而不是让模型凭记忆伪造来源。
- 搜索失败会返回明确错误，不会无限保持工具调用中。

### 3.5 附件和可编辑文件

- `files_list`、`files_search`、`files_read` 支持附件清单、段落检索和分段阅读。
- `files_create` 可生成 TXT、Markdown、CSV、JSON 和 PPTX 文件。
- 增加专用 PPT/PSD 可编辑文件流程。
- PPT/PSD 功能由后台单独开关，并指定具备该能力的 OpenAI 兼容服务商和线路。
- PSD 必须先提供 JPG、PNG 或 WebP 参考图；未配置服务商时返回明确的“功能未开放/配置不可用”，不会静默失败。
- 生成文件归属当前用户，并进入受控文件存储和清理流程。

### 3.6 助手工具和确认卡

当前助手工具包括：

- 联网与资料：`web_search`、附件列出/搜索/读取。
- 任务诊断：`task_status`，读取本人任务真实阶段、耗时、重试、失败、扣费和退款。
- 文件输出：TXT、Markdown、CSV、JSON、PPTX，以及配置后的 PPT/PSD 路径。
- 媒体操作：抠图、压缩、放大、裁剪和切图。
- 公共图片搜索：显示来源与授权信息。
- 网页截图：仅限公网网页并受安全限制。
- 工作区跳转：将需求和素材发送到受支持的站内工作区。
- 参考图复刻草稿：把参考图和目标转换为可编辑画布草稿。
- 商品导入：读取公开商品页面，准备导入 AI 电商。
- 交付导出：打包图片、提示词、参数和清单。
- 站内操作：仅允许跳转到许可的用户端页面。

所有会修改工作区、开始生成、产生费用或导出文件的动作先显示确认卡；用户确认前不执行。助手不开放任意 Shell、SQL、后台管理、支付或无限制浏览器控制。

### 3.7 对话中的资产链接

- 从助手消息中识别生成文件和可保存的资源链接。
- 用户可直接把对话中的具体资源加入资产库，而不是只提供一个“前往资产库”的笼统入口。
- 删除或替换助手输出时，关联对象进入延迟清理队列，避免 OSS 残留。

### 3.8 运行中引导

- 当任务正在执行时，界面可提供下一步需求整理和排队引导。
- 引导不会伪造任务进度，也不会覆盖正在运行的消息。
- 用户可继续组织后续任务，充分利用等待时间。

## 4. 无限画布

### 4.1 Agent 的画布“视野”

- Agent 可读取画布状态、当前选择、节点摘要、连线关系和视觉快照。
- 支持定位节点、检查节点详情、检查图片视觉内容，减少只凭文字猜测画布的情况。
- 节点、连线、画布范围和图片信息以结构化上下文提供给模型。
- Agent 的联网搜索能力与 AI 助手一致，可在需要资料时调用真实搜索。

### 4.2 Agent 操作能力

- 创建、移动、更新、删除节点和连线。
- 复制选择、创建图片操作节点、更新生图配置、创建附件节点。
- 替换工作流输入、执行选中节点、重跑选择、继续执行下游节点。
- 查询生成状态、搜索提示词、查询/添加资产、站内导航。
- 创建检查点、撤销、重做、查看 Agent 操作历史、恢复指定事务和导出快照。
- 高风险或产生费用的动作通过计划和确认后再执行。

### 4.3 节点交互修复

- 节点重命名改为更直接的弹窗输入，降低名称修改成本。
- 文本节点优化直接编辑和生图操作布局，移除多余“编辑”按钮。
- 节点顶部操作收敛为更小的圆角工具区，避免占用画布。
- 节点更多操作使用三点菜单，并修复点击外部无法关闭的问题。
- 画布节点不再直接展示“复制”和“信息”按钮；侧边栏仍保留节点信息。
- 节点副标题、内部 ID 和不必要的尺寸信息被移除或限制显示，避免暴露内部标识。
- 导出选中改为图标操作；“运行工作流”操作位置经过调整。
- 右键菜单和多选连线删除能力得到补充。

### 4.4 粘贴、图片和参考图

- 修复画布内部复制后，再复制外部文本或截图仍粘贴旧节点的问题。
- 支持从系统剪贴板粘贴截图图片和外部图片数据。
- 配置连接参考图后显示小型预览，便于确认输入来源。
- 多图节点可收起和展开，非主图也可双击查看大图。
- 图片信息面板改为读取真实图片信息。
- 锁定比例缩放时按完整图片比例布局，减少节点两侧无意义空白。

### 4.5 真实生成状态、重试和取消

- 画布任务状态区分：排队、准备参考图、上游生成、获取结果、保存图片、成功、失败、取消。
- 状态通过任务事件和轮询同步，不要求用户刷新页面才能看到变化。
- 重试任务会清理上一次运行阶段，并从 `0s` 重新计时。
- 单线路临时失败也会消耗配置的重试预算，不再因为没有备用线路而跳过重试。
- 已提交上游的任务取消前必须确认，提示可能继续生成和不退款的真实后果。
- 上游已经返回失败文本或异常终态时，任务停止转圈并显示可读原因。

### 4.6 性能与稳定性

- 减少频繁全量状态读取，更多使用局部状态和任务进度事件。
- 批量更新节点和连接，降低 React 重渲染和画布抖动。
- 图片节点加载、展开和预览采用稳定尺寸，避免动态内容造成布局跳动。
- 页面切后台或重新进入时恢复任务状态，避免重复执行。
- 工作流浏览器锁、心跳和检查点降低多个页面同时执行同一画布的风险。

### 4.7 工作流产品化的最终状态

本轮曾实现以下底层能力：版本、发布、运行记录、逐节点诊断、浏览器租约、服务器执行器、批量任务和结果策略。对应迁移 `00103`、`00107`、`00108` 已保留。

但最终决定是：

- 面向普通用户的“使用工作流”、发布版本、批量运行和服务器无人值守执行入口已撤下。
- 应用不再注册产品化路由、调度器或服务器执行器，也不再主动读写相关产品化表。
- 数据库表和迁移文件暂时保留，避免回滚迁移、破坏版本连续或误删已存在数据。
- 画布本身的节点编排、Agent 工作流草稿、当前页面内的运行/重试/状态诊断仍保留。

因此，不能把“工作流产品化”写成当前对客户开放的新功能。

## 5. AI 电商、文生图与通用生成

### 5.1 统一真实状态

- 文生图、AI 电商、AI 助手和无限画布共享统一任务阶段语义。
- AI 电商状态显示移动到操作按钮附近，不在页面重复占位。
- 用户看到的是排队、准备、上游生成、获取结果、保存等真实阶段，而不是只有笼统“生成中”。
- 状态变化通过事件和受控轮询更新，失败和取消进入终态后停止轮询。

### 5.2 取消策略

- 尚未提交上游：取消后立即停止并退回冻结积分。
- 已提交上游：弹出明确确认，说明本站只能停止等待/收图，上游可能继续生成，本次积分不会退回。
- 已完成图片保留；批量任务允许部分完成、部分失败或取消。

### 5.3 重试与耗时

- 临时上游不可达错误可按配置进行重试。
- 没有备用线路时允许重试同一线路；有备用线路时优先故障转移。
- 每次重试重置任务开始时间和阶段，前端耗时从 `0s` 重新计算。
- 区分排队耗时、上游运行耗时、结果拉取和保存阶段，避免把“未开始”误认为生成耗时。
- 上游原始失败信息经过安全清洗后返回用户，不再只显示“所有线路失败”。

### 5.4 用户历史记录

- 失败和已取消任务使用不同视觉状态，不再共用错误展示。
- 历史详情显示生成耗时，并在可用时展示真实失败信息。
- 内部任务 ID、服务商 ID、线路 ID 和内部错误前缀不暴露给普通用户。
- 历史媒体 URL 增加存储回退处理，降低旧记录图片无法显示的问题。

## 7. 开放 API

### 7.1 用户能力

- 新增 `/developer-api` 管理页。
- 用户可创建、轮换和撤销 API Key；明文 Secret 只在创建或轮换时显示一次。
- Key 可配置权限 Scope、模型白名单、过期时间、每日/月任务额度和每日/月积分额度。
- 支持读取模型、上传参考图、创建任务、查询任务和鉴权读取文件。
- 创建任务支持 `Idempotency-Key`，网络重试不会重复创建任务或重复冻结积分。
- Open API 复用站内模型开放状态、钱包、并发、队列、成本保护和文件权限，不绕过业务规则。

### 7.2 Webhook

- 用户可配置只允许公网 HTTPS 的 Webhook。
- 支持任务成功、失败和取消终态事件。
- Webhook Secret 只显示一次，投递携带签名。
- 失败投递按指数退避重试；达到上限后进入死信，用户可手动重投。
- 页面提供投递状态、HTTP 响应、尝试次数和最后错误。

### 7.3 API Key 安全加固

- 支持 IP/CIDR 白名单，最多 `20` 项。
- 支持每分钟请求上限和每日上下行字节额度。
- 记录最近使用时间和最近使用 IP。
- 异常使用可自动冻结 Key，后台可查看冻结原因并解冻。
- API 访问事件进入安全审计，用于识别暴力请求、流量异常和密钥泄露。

### 7.4 当前开放状态

- Open API 代码、界面和文档已实现。
- `developer_api` 页面开关默认关闭，当前仍是内部测试功能。
- 后台明确打开页面控制前，普通用户不应看到或使用该入口。
- 接口文档见 `docs/OPEN_API.md`。

## 8. 成本利润系统

### 8.1 计费数据

- 新增统一 `usage_profit_entries` 账目，记录来源、用户、API Key、工作区、模型、服务商、线路、数量、收入、上游成本和毛利。
- 图片任务成功、失败、部分成功和提交上游后的取消都会形成对应账目。
- 助手文本调用记录输入、输出、推理和总 Token，以及实际结算积分和上游成本。
- `1` 积分继续按 `1` 分钱统计。

### 8.2 模型成本配置

- 图像和对话模型支持“上游成本/次”。
- 放大模型支持普通档和高档上游成本。
- 支持“允许零积分”和“允许价格低于成本”两个显式开关。

## 15. 任务可靠性、并发与性能

### 15.1 调度和队列

- 保留用户公平调度和全局容量控制，避免单个大批量用户长期占满执行槽。
- 运行任务与图片单位分别计数，图片任务不会只按“一个任务”低估压力。
- 队列状态写入数据库，Worker 重启后可恢复。
- 助手任务使用对话内串行、用户间并行的队列模型。

### 15.2 上游阶段和完成收取

- 任务在参考图准备完成、真正提交上游后才进入“上游生成”阶段。
- 上游完成后进入结果拉取，再进入对象存储保存，阶段分别可观测。
- 结果拉取和对象保存不再被笼统算成上游生成时间。
- 上游返回文本错误、空结果或异常状态时及时终止并传播失败原因。

### 15.3 重试和故障转移

- 临时不可达错误按配置重试。
- 有替代服务商/线路时优先切换；只有一条线路时允许重试原线路。
- 重试清空上次完成声明和阶段字段，避免旧状态污染新一轮。
- 达到重试上限后进入失败终态并结算/退款，不再无限转圈。

### 15.4 状态同步

- 任务事件携带阶段和终态，Web、画布、电商和助手可即时更新。
- 事件丢失时仍有低频轮询兜底。
- 终态停止轮询，避免后台页面和用户端频繁访问接口。

## 17. 安全与反滥用

### 17.1 响应脱敏

- 普通用户响应移除服务商 ID、线路 ID、内部端点、内部任务关系和调试字段。
- 上游错误先做安全清洗，再返回对用户有用的失败原因。
- 助手 `task_status` 只返回本人任务的业务状态，不返回内部路由和凭据。

### 17.2 请求与注册限制

- 登录、注册、验证码、上传、任务创建和高风险接口增加独立限流。
- 支持用户级并发和使用额度控制。
- 上传对象记录实际字节数，并校验用户存储额度。
- 下载和文件接口增加出口流量保护，避免被当作免费文件分发节点。

### 17.3 上传安全

- 上传计算 SHA-256，可配置恶意文件哈希黑名单。
- 支持接入 ClamAV 扫描；未配置时不会伪装成已扫描。
- 为外部内容审核保留安全 Hook。
- 校验 MIME、扩展名、尺寸、大小和解码结果，降低伪装文件风险。

### 17.4 风控中心

- 新增 `/security-center`。
- 查看安全风险事件、临时/永久封禁、API Key 冻结、文件哈希规则和支付对账。
- 风险事件包含类别、等级、分数、动作、来源和可读原因。
- 管理员可解除封禁、解冻 Key、处理风险和管理文件哈希规则。

### 17.5 支付证据和对账

- 支付回调保存脱敏证据和金额结果。
- 对比本站订单状态、预期金额和支付方已付金额。
- 标记匹配、金额不符、状态不符或缺少证据的记录。
- 对账结果进入安全中心，避免只依赖某一次回调成功。

### 17.6 密钥和凭据

- API Key 只存哈希，明文只显示一次。
- 支持轮换、撤销、冻结、过期、IP 限制和额度限制。
- 环境变量示例不包含真实生产密钥。
- CI 增加密钥泄漏扫描。

7. 验证成本利润、Agent 质量、安全中心和用户画像查询。
