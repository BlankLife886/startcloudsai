# PSD 分解工作台设计

## 产品定义

本页的“分解”指把JPG/PNG/WebP图片转换为分层PSD，复用项目已经存在的可编辑文件上游任务。不声称能够无损恢复原始设计文件，也不把程序近似抠图伪装为真实原始图层。

现有PSD解析器主要读取文件结构和图层名称；它不是完整的浏览器Photoshop渲染器。因此首版不承诺任意PSD导入、混合模式重建、字体编辑或智能对象恢复。如果需要“已有PSD拆出每层PNG”，应作为独立后续模式实现并引入经过验证的PSD解析/渲染库。

## 页面结构

路由 `/psd-decompose`。桌面工作台，不使用营销hero或装饰性卡片堆叠。

顶部工具栏：PSD分解名称、当前任务状态、选择图片、开始分解或取消、下载结果。
左侧输入栏：原图缩略图、文件名、尺寸、大小、拆层要求、当前服务可用状态。
中央画布：完整原图，棋盘格透明底，适应画布/缩放控制，不裁切。空态用真实平台样例图展示输入，不假装已有完成任务。
右侧交付栏：真实任务阶段、服务错误、主PSD和素材ZIP；仅根据服务端返回的产物列出文件。未返回图层信息时不绘制假的图层树。
下方或侧栏历史：当前账号最近的PSD工作区会话，选中后通过服务器恢复任务。

## 核心流程

1. 登录用户选择不超过20MB的PNG/JPG/WebP，前端检查类型、大小、可解码性和像素上限。
2. 查询助手配置，服务未开启时禁用提交并明确状态。
3. 用户填写可选拆层要求，确认费用风险。首版沿用助手的模型计费，不伪造专属固定价格。
4. 上传到现有本人文件接口，创建带PSD工作区前缀的独立助手会话与幂等run。
5. 通过现有run读取/等待机制获得状态，刷新后可从历史恢复。
6. 成功显示站内鉴权下载的PSD与ZIP；失败展示真实错误，重试创建新run但不自动重复付费。

## 数据与安全

所有任务仍属于本人assistant workspace，历史会话明确标识PSD来源。图片不保存在public目录。下载只使用同源鉴权文件路径，不接受模型返回的任意脚本URL。

不得导出API Key、上游临时访问凭据。未确认不自动提交；切换账号、卸载组件取消本地轮询，不能把上一账号结果展示给新账号。取消本地等待不等于取消服务端任务，服务端取消需用户点击并遵守费用规则。

## 状态与验收

状态覆盖未登录、无图、读取失败、服务关闭、上传中、提交中、queued、running、succeeded、failed、canceled、断线恢复。

验收项：上传校验、重复点击不重复提交、刷新恢复、换账号隔离、取消返回、下载权限、错误重试、缩放不改布局、1280×720无重叠。真实PSD质量以Photoshop打开、图层内容、透明通道、文字是否可编辑为验收依据；未做真实上游验证时必须注明，不得称为生产质量已通过。

## 后续增强

专属服务报价、服务端PSD项目表、图层缩略图提取、原图/合成对比、逐层导出与蒙版校正需要下一阶段专门实现，不能用静态假数据代替。
