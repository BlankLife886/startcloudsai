# 开发者控制台与演示工作区

## 页面

- `/developer-api`：真实账号控制台，沿用登录、页面控制和服务端权限。
- `/developer-api/demo`：独立演示入口，无需真实密钥。此路由固定使用内存模拟适配器，不能通过query参数切换为真实写操作。
- `/developer-api/docs`：现有开放API文档。

新控制台包括概览、API Keys、Webhooks、投递记录、模型目录和快速接入。概览分为三层：高饱和紫蓝主面板突出今日任务和提交预算，旁侧展示有明确统计范围的回调状态；四张独立资源卡作为次级摘要；凭据、接入和记录在下方展开。22–26px圆角卡片、胶囊导航和14px圆角按钮形成统一视觉。界面支持明暗主题，适配375、747、1280和1440px宽度。

下拉菜单使用自定义外观和键盘选择，复选框、开关、数字步进及日期日历统一设计。日历支持方向键、PageUp/PageDown切月、Escape关闭和焦点返回；在原生dialog内挂载浮层，避免被表单滚动区裁剪。保留原生表单语义及数值校验。

切换面板与打开弹窗采用约0.22–0.24秒的GSAP淡入，菜单、按钮、开关及卡片提供短促的交互反馈。动画仅作用于本控制台，组件更新或离开时清理，遵循系统的减少动态效果设置。

## 演示隔离

演示实例保存在组件内存，刷新页面或点击重置会恢复样例；不写Cookie、localStorage或业务数据库。创建/轮换返回的凭据均以`demo_`开头，不能用来请求真实API。

可切换常规运行、异常状态、空白空间。支持Key创建、轮换、撤销、过期/冻结状态；Webhook创建、编辑、启停、删除；失败投递进入pending，再次刷新显示delivered。这里只模拟状态变化，不发送真实回调。

模拟请求记录、耗时、请求体、响应体、报价与图片返回只在演示模式出现，均标记为示例数据。模型ID和价格为示例值；“模拟图片返回”使用固定的1×1 PNG展示Base64响应格式，不发送图片请求。

## OpenAI Images 快速接入

快速接入默认选择“OpenAI Images · 生图”，展示统一 `/v1` Base URL、真实模型ID或演示占位值，以及包含 `Idempotency-Key` 的 `POST /images/generations` cURL。概览的模型查询地址同步为 `/v1/models`。只复制示例代码，不发送生图请求；界面明确说明用户实际执行代码才会创建任务并消耗积分。

“任务 API · 报价”保留 `/api/open/v1/tasks/quote` 的安全报价入口，两种协议分别显示对应的返回格式。演示模式保留“模拟报价返回”，并增加“模拟图片返回”；选择任一模拟按钮会同步选择对应协议，避免示例代码与响应格式不一致。

接入流程说明测试Key权限、公开模型ID、Base URL、Base64保存、幂等重试和504后的任务恢复。完整文档提供可复制的Python SDK、cURL生图和multipart编辑示例，首版范围为Images兼容子集。控制台不声称提供聊天、Responses或完整OpenAI协议。

## 本轮补齐的功能

1. Key详情展示权限、模型范围、IP白名单、有效期、最近IP、日/月任务数、提交预算和流量。
2. 过期Key不算可用；过期但未撤销及冻结Key仍占保留名额，达到10个时阻止继续创建。
3. 列表支持搜索、状态/端点筛选和本页分页；回调统计明确限定服务端最近100条记录。
4. 只有dead且端点启用的投递允许重投；重投不重置累计尝试次数。
5. Key额度做整数/范围/月额度不小于日额度的前端校验，服务端校验仍是最终依据。
6. 每类资源独立处理读取失败，保留已成功的数据；真实失败不会切换成模拟数据。
7. 切换真实账号时重新建立页面状态，中止旧读取；迟到响应和一次性密钥不会显示到另一账号。
8. 原生dialog提供焦点约束和Escape处理，写操作进行中禁止关闭；一次性密钥通过单独确认关闭。
9. OpenAI Images生图和旧版文生图报价示例均可复制cURL；只复制示例，不自动发送付费任务。

## 仍需后端能力的部分

- Key名称/权限/额度编辑：目前没有更新接口，UI没有伪造编辑保存。
- 用户请求日志、按日趋势、成功率、P95延迟：底层部分访问事件存在，但没有对应用户查询API。真实模式不显示虚构指标。
- 全量Webhook历史、分页、payload、响应正文、下次重试时间：现接口只有最近100条摘要。
- 实际净消费：当前用量是累计提交时的预留预算，退款不减少此计数。需要独立按账本聚合的统计接口。

上述能力适合后续迭代，模拟界面不能作为这些后端能力已完成的证据。本轮没有开启原本关闭的真实API服务、创建真实Key或发送真实Webhook。

页面：`npx playwright test tests/e2e/developer-console.spec.js --project=chromium --workers=1`。演示交互断言不请求真实开发者接口；真实模式的失败用例使用路由拦截提供测试响应，不操作真实账号数据。
