# Data Safety Declaration Source

Use this file as the source of truth when completing App Store App Privacy and Google Play Data Safety forms.

| Data category | Linked to user | Tracking | Purpose |
| --- | --- | --- | --- |
| Name / profile | Yes | No | Account and app functionality |
| Email address | Yes | No | Authentication and account recovery |
| User ID | Yes | No | Account synchronization and security |
| Photos and videos | Yes | No | User-requested AI creation and storage |
| Prompts, AI conversations and other user content | Yes | No | AI features and content management |
| Customer support content | Yes | No | Feedback handling |
| Purchase history and credit ledger | Yes | No | Entitlements, accounting and support |
| Device/session metadata and IP address | Yes | No | Fraud prevention, security and diagnostics |

The app does not use advertising identifiers and does not perform cross-app tracking. Camera, photo, microphone and speech permissions are requested only when the user invokes the corresponding feature.
