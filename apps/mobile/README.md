# 星空云绘移动端

用户端 Flutter App。当前能力包括公开提示词详情与点赞/收藏、社区作品、邮箱验证码登录、服务端模型配置、文生图与参考图创作、模型设计、插画染色、智能去背景、基础 AI 助手文本对话、个人素材库与分组、任务状态恢复、完成提示、作品详情、停止生成、原图保存/分享、社区投稿与审核状态、通知中心、每日签到、问题反馈、个人资料编辑、作品列表、积分明细、订阅状态与历史订单、体验资格与成长福利，以及公开公告与版本更新。管理端与无限画布不在移动端范围内。

首版图片创作主线仅继续迭代文生图与 AI 助手；UI 设计和 AI 电商不进入移动端首版。已经完成的模型设计、插画染色与智能去背景继续保留，其他用户端基础功能照常维护。

## 当前闭环

- 创作：安全自动保存提示词和模型草稿，设计页会显示最近草稿摘要并可直接继续；画面描述可一键带入 AI 助手优化且不会自动发送；可直接复用个人素材库，或从相册多选、拍照添加参考图；多张参考图支持拖拽调整模型接收顺序并明确标记主参考，同时遵守模型能力和任务接口 6 张上限；本地图片会自动将 HEIC/EXIF 方向归一化为 JPEG 后上传；付费生成会在上传参考图前预检钱包余额，确认页展示当前可用积分和生成后预计余额，余额不足时给出准确差额并可前往钱包。
- 模型设计：支持人物或产品主体描述与参考图、多视角选择、严格还原/专业优化、背景、细节、分辨率和模型能力约束；可生成多方案设定板，或按视角创建独立任务并在蓝图舞台切换结果。
- 染色：从素材库、相册或相机选择线稿，可追加模型允许数量的配色参考图；支持配色预设、画幅、分辨率、质量和批量张数，并在同页恢复状态和切换线稿/结果预览。
- 去背景：从个人素材、相册或相机选择单张图片，按服务端工具模型与实时积分价格提交；页面持续恢复任务状态，并在棋盘格中预览透明 PNG 结果。
- 助手：复用服务端对话模型与积分价格，支持模型和推理强度选择、新建与切换历史对话、按标题或消息正文多关键词搜索历史、删除某轮提问及其后续内容、文本发送、语音实时转写、从相册或个人素材库添加最多 4 张参考图，首张明确标记为主参考；外部素材进入时会自动选择同模式下支持图片的模型，已有回复运行中则等待其结束后切换，不中断当前任务；支持 SSE 实时回复与思考过程、轮询断线恢复、停止回复和网络同步失败重试；多图生成结果支持从所点图片进入全屏预览，通过左右滑动、页码和缩略图轨道连续浏览，可查看、复制每张图片的实际提示词或一键带入图片模式继续创作，并可一键保存或分享全部结果，单张图片也可缩放、继续编辑、保存、分享和删除，删除最后一张时同步移除该图片消息；切换新对话、历史、快捷任务或模式时会先停止语音识别，避免转写串入其他上下文；未发送的文字与参考图会自动保存到当前环境隔离的设备私有草稿，并在返回助手时恢复，成功发送或手动清除后删除；发送前会按当前模型和推理强度预检钱包，价格区展示可用积分及发送后预计余额，余额不足时在上传参考图前拦截并给出准确差额；回复支持可选择的 Markdown 标题、列表、引用、表格和代码块，复制与带入文生图仍保留原始内容，远程 Markdown 图片不会自动加载；完整回复支持赞同、不赞同及取消反馈，选择状态随账号会话持久化；历史用户消息会保留参考图预览，失败或停止后可恢复最近一次提问。移动端仅使用独立助手工作区，不读取或创建无限画布会话。
- 素材：从相册或相机上传到个人素材库，接近列表底部时自动续载 cursor 下一页并支持内联失败重试；支持按名称多关键词搜索已加载素材，无匹配时可继续加载下一页查找，以及容量总览、分组筛选、重命名、移动分组和删除；素材详情可全屏缩放查看、保存原图或调用系统面板分享，并提供独立操作进度反馈；详情和全屏预览均可将素材直接带入文生图或 AI 助手，复用远程文件、不重复上传，进入助手时保留未发送文字和已有参考图并将当前素材置于首位。
- 灵感：支持服务端搜索与分类、cursor 连续浏览、只看我的收藏、完整提示词预览、复制、点赞、收藏，并可将提示词带入创作页。
- 任务：提交后进入作品列表；账户级 SSE 实时同步状态，断线时批量轮询兜底，App 回到前台时立即恢复并提示完成结果。
- 作品：支持提示词、模型和类型的多关键词联合搜索，按状态筛选；当已加载数据无匹配时，键盘搜索键会自动向后查找更早的分页记录。接近列表底部时会自动续载 cursor 下一页，并提供内联失败重试与完成提示，列表进入详情时会携带当前作品快照，单条详情同步失败也能继续预览和处理；详情页支持选择或一键复制完整提示词，查看模型、画幅、清晰度、质量和生成张数，以及在主画面或全屏预览中滑动、点击缩略图切换多个结果，全屏支持缩放、页码、直接保存或分享当前图片，并在关闭后同步浏览位置；支持停止生成，详情底部可单图保存与分享，或多图一键保存和分享全部，并可沿用原参数再次创作；支持终态作品删除，被后续创作引用时可二次确认级联删除。
- 社区：公开作品可按分类 cursor 分页浏览，查看作者、标签、多图详情并全屏缩放；详情页支持按不适宜内容、版权、垃圾广告、骚扰或其他问题举报，并可二次确认屏蔽作者，屏蔽后立即移除其作品且服务端后续分页持续过滤；自己的作品不显示举报或屏蔽入口。账号安全页可查看完整屏蔽列表并解除屏蔽，恢复对应作者内容。自己的成功作品可填写标题、选择分类并投稿，个人中心可按标题、审核状态和驳回原因搜索并叠加状态筛选，接近底部自动续载投稿记录，支持内联失败重试、复制未通过投稿的完整审核意见，以及撤回后重新投稿。
- 通知：个人与全站通知合并分页，可按标题、正文和类型搜索并叠加未读筛选，自动续载失败时支持页尾重试；任务通知可直达关联作品详情，订单到账通知可拉取并打开准确订单，其他通知支持对应业务页面跳转；支持在列表直接标记单条已读、左滑删除单条、全部已读和清空，底部“我的”导航、个人中心、任务完成及前后台恢复会同步未读数。
- 签到：展示连续 7 天奖励、本月签到日历和累计数据；奖励节点与已签到日期可点击查看准确积分和连续天数，领取成功后以轻量状态动画反馈并立即同步积分钱包。
- 钱包：展示余额、累计入账/消费/退回和 cursor 分页明细；余额构成可直接进入普通、体验或冻结明细筛选，支持完整 CSV 账单导出及业务错误提示。商店分发版本不提供外部支付或兑换入口。
- 会员与订单：展示当前订阅和 cursor 历史订单，订单可按处理状态筛选并复制订单号，通知关联订单会高亮并自动打开详情；待支付订单仅能查看或关闭，不显示外部支付链接、二维码、价格套餐或兑换入口。
- 福利：展示限量体验活动、申请审核和专属体验积分；同步创作里程碑、失败补偿、建议奖励与好友拼团，拼团邀请码可复制或调用系统面板分享，并明确展示有效期。
- 反馈：支持分类提交问题或产品建议，可按标题、正文、分类、状态和管理员回复搜索并叠加状态筛选；接近底部自动续载 cursor 下一页并支持内联失败重试，详情展示处理进度、管理员回复和建议采纳积分。
- 资料：个人页汇总钱包、创作状态和最近任务；支持修改头像、用户名、简介、所在地与个人网站，个人网站可从资料区安全打开，并可选择付费创作提交前是否再次确认预计积分；退出登录前会二次确认，避免误触清除本机会话。
- 外观：支持跟随系统、浅色和深色模式，明确展示当前实际生效的外观与实时预览，选择会在本机持久保存。

- 账号与安全：集中展示当前登录邮箱和系统安全存储保护状态，可查看当前与其他有效登录设备、退出单台陌生设备或保留本机并退出其他设备，也可分页读取并解除社区作者屏蔽；支持生成并通过系统面板分享不含密码、会话凭证或图片二进制的 JSON 账号数据副本；同时可跳转管理设备权限，并在独立本地存储页查看图片缓存与文生图、AI 助手、问题反馈草稿状态，分别清理缓存或经确认清理未发送草稿。退出登录从资料编辑中归位到账号安全页并保留二次确认，避免资料操作与会话操作混杂。
- 账号注销：账号安全页提供可在 App 内完成的永久注销流程，必须通过当前登录邮箱验证码重新认证并再次确认；服务端原子地匿名化身份、清除全部会话与 API 凭证、隐藏公开投稿并释放原邮箱，进行中的创作或助手任务会明确阻止注销，必要订单与安全记录仅以匿名账号留存。
- 网络恢复：幂等 GET 请求遇到连接失败、超时或 408/502/503/504 时会先进行一次短退避重试，POST/PUT/PATCH/DELETE 不自动重试，避免重复创建任务或重复扣积分；REST 请求和私有文件下载会统一识别真实连接中断，页面中央持续显示轻量重试提示，连接恢复后自动反馈并停止重复提醒，实时事件流单次重连不会被误判为设备断网。
- 后台隐私：App 进入系统任务切换器、后台或隐藏状态时会立即用主题化隐私页覆盖对话、作品、邮箱和通知等内容，同时停止底层点击与辅助功能读取；回到前台后自动恢复当前页面。
- 会话：启动登录页时读取服务端可用登录方式与邮箱域名，验证码服务未配置时禁用无效提交并支持重试；验证码重发等待使用真实截止时间，App 从后台恢复时会立即校准；个人深链在请求私有数据前统一检查登录状态，验证后自动返回目标页面；登录会话使用服务端现有 `sc_session` Cookie 并保存到 Keychain/Keystore，REST、私有图片或实时连接返回 401 时会立即清理用户缓存并提示重新登录。
- 深链：iOS 与 Android 均注册 `starcloudsai://app/<path>`，可从通知、网页或其他 App 直达现有路由；私有页面仍会先验证登录，无效地址进入可恢复的错误页。HTTPS Universal Links / App Links 需在取得 Apple Team ID 与 Android 正式签名证书指纹后部署域名关联文件。

## 运行

Debug 构建默认连接本机 API：

```bash
flutter run
```

## Android 发布签名

Release 构建不会使用 debug key。将 `android/key.properties.example` 复制为不纳入版本控制的 `android/key.properties` 并填写上传密钥，或在 CI 中设置 `ANDROID_KEYSTORE_PATH`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD`。缺少签名时 Release 任务会直接给出错误，避免产出不可上传的包。

显式指定本机 Go API：

```bash
flutter run \
  --dart-define=APP_ENV=development \
  --dart-define=API_BASE_URL=http://localhost:8000
```

Android 模拟器访问宿主机时，将地址改为 `http://10.0.2.2:8000`。真机调试使用同一局域网内可访问的 HTTPS 或开发机地址。

Release 构建默认连接 `https://starcloudisai.com/api/v1`。开发、预发布和正式环境使用独立的 Keychain/Keystore 会话键，不会互相复用登录状态。

## 结构

```text
lib/
├── app/       # 主题、路由、应用入口
├── core/      # 环境、API、会话存储与通用组件
└── features/  # auth、discover、create、tasks、profile
```

当前服务端仅提供 HttpOnly Cookie 会话。App 将 `sc_session` 保存到 Keychain/Keystore，并让 REST 与私有媒体共用该凭据。后续服务端提供移动 Bearer 会话后，只需替换 `SessionStore` 与 `ApiClient` 的凭据注入逻辑。

## 设备配置

iOS 需要可用的 Simulator Runtime 或已开启开发者模式的真机。Android AVD 除设备配置外还必须完整安装对应的 `system-images`；仅有 `package.xml` 无法启动模拟器。
