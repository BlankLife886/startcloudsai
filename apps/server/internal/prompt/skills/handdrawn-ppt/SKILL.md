[手绘PPT Skill / HANDDRAWN-PPT]
把用户内容画成中文手绘技术讲解风的整页图。以下是执行约束，不要把规则、版式名称或分析过程画进图里。

一、画面
- 完整的整页图片，图里直接包含图示和中文文字。
- 近白暖色纸面（约 #FBFAF5），只有极轻的纸纹；不要黄纸、米黄旧纸。默认不画整页边框，四角只留极淡的网格、点阵或刻度。
- 中间是一个小而精的语义图示：细的近黑手绘线、铅笔排线，标签后面是很浅的马克笔色块（浅蓝、灰绿、浅杏、淡紫），少量强调色 #D66F4D。
- 正文页图示约占画面宽 50–60%、高 35–45%；封面隐喻图约占宽 50–55%。四周大量留白。
- 人物尽量不画，最多角落一个很小的读者形象。

二、母版（一组图里每页固定）
- 左上角小页码，如“04 / 10”。
- 标题居中，中等大小的硬笔手写中文，下方一条短的浅蓝下划线；标题下一行小字副标题。
- 正文页标题保持同样的视觉大小，字少也不放大成海报标题。
- 只变化中间图示区；不靠换位置、换边框、换字体、换配色来制造变化。

三、文字
- 标题 5–12 字，副标题 3–12 字，主标签 2–5 个，补充说明 0–6 条、每条 2–6 字。
- 用户给出的标题和标签一字不改照抄；除此之外不写别的字，不写长段落。
- 硬笔字，不用毛笔书法、童趣涂鸦字或粗大广告字。

四、画幅
- 文章封面 21:9，正文配图和普通页 16:9；用户指定时以用户为准。画幅以任务参数为准。

五、禁止项
- 整页边框、阴影、渐变、霓虹色、大面积彩色卡片、巨大字体、底部大引语框、可爱海报风、多个人物、错字或凑数的文字。

六、在 AI 助手里使用时（生图模型请忽略本段）
- 流程：读内容 → 必要时提问 → 规划整组页面 → 用户确认 → 出图 → 检查。
- 用户上传文档时用 files_search / files_read 读；内容不全且会改变结果时用 ask_choices 问受众、页数、要不要封面，最多 3 个问题，信息够就直接按默认值做（文章 8–12 页，短观点 5–8 页）。
- 规划时先读 narrative-planning.md 和 slide-archetypes.md，列出每页：页码、标题、一句话要点、版式、必须出现的文字。用户只要规划时到此为止。
- 出图前读 visual-dna-v6.md 和 prompt-patterns.md，写一段统一的风格锁定，逐字放进每页提示词，只改中间图示和文字。
- 用一次 propose_image_action 提交整组：每页一个 items，写清标题、该页提示词和 ratio（封面 21:9，正文 16:9）；页数超过单次上限就分批。
- 出图后按 output-quality.md 检查；某页文字写错时先减少该页字数再单独重出。需要打包时用 delivery_export。
- 参考资料里提到的本地存图、拼总览图、风格锚点图片、脚本或确定性叠字在本平台不适用，以本段为准。
