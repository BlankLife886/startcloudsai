[手绘画风 Skill / HAND-DRAWN-STYLES]
按用户指定的手绘画风画一张图。以下是执行约束，不要把规则、画风编号或分析过程画进图里。

一、通用要求
- 只用一种画风，整张图从线条、上色、纸面到人物比例都保持这一画风，不混入其它风格。
- 画面是完整插画，不是拼贴；除非用户给了要写的文字，否则图里不加任何文字、水印或签名。
- 画幅以任务参数为准。

二、常用画风要点（完整配方见参考资料）
- 极简线条讲解漫画：纯细黑线火柴人，圆角多格分镜，每格标题加一句说明。
- 蜡笔童涂：像 5 岁小孩用蜡笔画的笨拙“坏画”，线条歪扭、涂色出框。
- 日系手绘动画风：柔和水彩、平滑渐变、暖光，单一焦点，背景简洁，云少而整。
- 水墨写意：毛笔黑墨、墨分五色、飞白留白，朱红小印章。
- 复古像素：8/16-bit 游戏精灵图，硬方块像素、有限调色板、无抗锯齿。
- 北欧绘本水粉：整画纸纹、大留白，丹宁蓝与芥末黄低饱和，极简小点眼人物。
- 暖色扁平绘本：圆润几何大色块、几乎无外轮廓线，蓝橙限定色板，暖白大留白。

三、禁止项
- 借用或模仿具体动画公司、作品、角色或在世画家的名字与形象。
- 把多个画风揉在一起，或在画风配方之外另加一套线条、五官、配色规则。

四、在 AI 助手里使用时（生图模型请忽略本段）
- 先读 protocol.md 识别画风。用户已指定编号、中文名或别名就直接用；只说“涂鸦”“手绘风”这类有歧义的说法，或没有指定时，用 ask_choices 推荐 3 套最合适的画风并附“其他（回复编号或名字）”，不要替用户直接挑。
- 取 styles.md 中对应编号的完整模板，逐字照抄，只按 protocol.md 的规则替换占位符；英文模板的占位符也填英文。不得摘句、改写或混配。
- 比例：用户给了就用；没给时纯风格不写比例，版式风格（1、4）只写结构提示。画在纸上的画风（2、7、10 轻量版）用户想要“像真的画在纸上”时，整段追加附录 A 的纸质感增强层。
- 默认用 propose_image_action 出图，prompt 放填好的完整模板；多张图时每张一个 items，同一组保持同一画风。用户说“只要提示词”时不出方案卡，按 protocol.md 的输出格式直接给代码块。
- 本平台暂不提供上游的“蜡笔童涂-潦草自画版”（需要固定锚点图和三阶段修正）；用户要亲子或家庭蜡笔画时，推荐 2 蜡笔童涂或 7 蜡笔实拍。
