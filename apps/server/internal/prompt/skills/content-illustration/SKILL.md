[内容配图 Skill / CONTENT-ILLUSTRATION]
把中文内容画成一张封面或正文配图。以下是执行约束，不要把规则、风格名称或分析过程画进图里。

一、风格
- 按用户指定的风格画；用户没指定时，用默认的手绘知识风：暖白纸感背景，黑灰细线手绘，低饱和浅色块，中文手写字，自然成熟、克制精致、留白充足，像高质量中文知识博主的手绘图解。
- 一张图只用一种风格；封面和正文可以按用户要求用不同风格。

二、封面（默认 21:9）
- 左侧约 45% 放主标题和副标题，右侧约 55% 放概念图、流程图或隐喻图；右下角可有极简小人加一句气泡，底部一句轻量判断句。

三、正文配图（默认 16:9）
- 不用封面的左标题右图结构；顶部可有小标题，中间是主体图解，周围少量短注释，底部一句判断式结论。
- 结构只选一种：闭环机制、横向流程、分类树、左右对比、结构类比、风险路径、光谱选择、随附场景。

四、图标（1:1）
- 用户要 logo 或图标时只画一个方形图标；除非用户要字标，不写品牌名、长文字或水印。

五、文字
- 中文清晰、无错字；用户给的标题和标签照抄；不堆密集小字，不出现英文乱码。

六、禁止项
- PPT 感、课程课件感、复杂信息图、高饱和色、水印；默认手绘知识风下还不要科技海报、3D 和可爱儿童插画。

七、在 AI 助手里使用时（生图模型请忽略本段）
- 先读 workflow.md，判断用户要的是封面、正文配图、整篇拆图、logo/图标，还是只要提示词或清单。整篇文章再读 article_breakdown.md，用户上传文档时用 files_search / files_read 读。
- 用户没指定有效风格时，不要替用户决定：按 style_options.md 的推荐匹配规则算出 3 套最合适的风格，用 ask_choices 一次问清风格（3 个推荐加“其他，回复风格名”）、要不要封面及比例、正文配几张（默认短文 3 张、中等 5 张、长文 7 张）；图标模式只问图标风格，固定 1:1、1 张。用户已指定风格时直接做，缺的数量按默认补齐。
- 写提示词：默认风格用 cover_prompt.md / body_prompt.md 和 visual_style.md；其它风格用 style_options.md 中对应风格的模板，并附上该风格的风格锚点。
- 出图用一次 propose_image_action：封面和每张正文各一个 items，各写 ratio（封面默认 21:9，正文 16:9；个别风格按 workflow.md 用竖版或 1:1）。
- 用户只要提示词或批量清单时，不出方案卡，按 workflow.md 的输出格式回复；需要文件时用 files_create 导出 md 或 json。需要打包时用 delivery_export。
- 用户要“怪诞小人”“小黑”风格时，告诉他改用 @小黑配图。
