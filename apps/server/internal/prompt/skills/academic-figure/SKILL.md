[学术配图 Skill / ACADEMIC-FIGURE]
把用户的论文内容画成一张顶会风格的学术配图。以下是执行约束，不要把规则或分析过程画进图里。

一、风格（默认经典顶会风）
- 纯白背景，扁平矢量风，干净的细线条和圆角矩形模块，像 CVPR、NeurIPS、ICLR 论文里的方法图。
- 信息密度高但不拥挤：模块内有子结构、嵌入缩略图、维度标注；流向清楚（左→右或上→下），用实线箭头表示主数据流，虚线表示反馈或可选路径。
- 标注用英文，字体清晰的无衬线体；模块名、公式符号、张量维度按用户给的原样写，不编造未给出的数字和符号。
- 默认配色 Okabe-Ito：主色 #0072B2，辅色 #E69F00，点缀 #009E73，其余为灰阶；用户指定配色或给参考图时以用户为准。

二、现代 ML 浅色风（仅在用户要求时使用）
- 纯白画布，内容放在白色圆角面板上，面板带极弱的投影；圆角友好字体（Nunito / Poppins 一类）。
- 用浅彩小方块（token）、彩色关键词文字、曲线和小插画来传达颜色，元素浮动排布，不层层嵌套边框。

三、图的类型
- 总体框架图、网络架构图、模块详解图、对比与消融图、数据或行为模式图；一张图只表达一种类型。

四、禁止项
- 3D 渲染、照片质感、渐变背景、霓虹色、大面积高饱和色块、装饰性插画抢主体、水印和 Logo、没给出的数值或公式。

五、在 AI 助手里使用时（生图模型请忽略本段）
- 用户上传论文时用 files_search / files_read 找到方法章节，先弄清模块、数据流、符号和维度；信息不足以画图时直接说缺什么。
- 风格默认经典风，写提示词前读 style-classic.md；用户要浅色风时读 style-pastel.md。
- 用户没指定配色时，用 ask_choices 一次问清：风格（经典顶会风 / 现代 ML 浅色风）、配色（经典风 A–H 或浅色风 P1–P4 的名称）、图的类型；用户已说明的项不再问。想自己取色的，告诉用户可以直接给 hex 色值。
- 按参考资料的四层结构写完整英文提示词：全局描述、分区详细描述、全局标注、风格规格；宁长勿短，不省略模块。
- 出图用 propose_image_action，提示词放英文全文，ratio 按图的类型选（框架图常用 16:9 或 3:2）；一篇论文要多张图时每张一个 items，并说明优先级。
- 用户只要提示词时，不出方案卡，按参考资料的输出格式直接回复；多张时可用 files_create 导出 md。
- 出图后按检查清单核对模块是否齐全、箭头方向、符号与维度，不对就改提示词重出。
