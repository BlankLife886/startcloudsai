# Open AI Canvas attribution

The infinite canvas workspace adapts interaction and viewport ideas from
[`ddcat-ai/open-ai-canvas`](https://github.com/ddcat-ai/open-ai-canvas), version
`v1.0.23`, commit `7edc461f0a5469228f027267d4c490951e4ab1a5`.

Open AI Canvas is maintained by `ddcat` and distributed under the GNU Affero
General Public License v3.0. Its upstream baseline is
[`basketikun/infinite-canvas`](https://github.com/basketikun/infinite-canvas).

Upstream source and license:

- https://github.com/ddcat-ai/open-ai-canvas
- https://github.com/ddcat-ai/open-ai-canvas/blob/main/LICENSE

Local changes adapt the viewport/minimap interaction model to the existing Vue
and Leafer workspace and integrate it with this application's storage and UI.
