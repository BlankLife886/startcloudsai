# Homepage motion references

The commercial homepage motion system is an original Vue implementation inspired by the
interaction patterns demonstrated by Vue Bits, including Gradient Blinds, Flowing Menu, Strands,
Card Swap, Scroll Float, Scroll Reveal, Text Type, Glass Surface, and Logo Loop.

Reference project: https://github.com/DavidHDev/vue-bits
