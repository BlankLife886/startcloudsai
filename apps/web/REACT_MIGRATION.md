# 主站 React 迁移基线

主站采用逐路由迁移。Vue 页面在对应 React 页面通过视觉与交互回归前继续承载生产流量；迁移期间不调整设计、不替换文案，也不套用其他组件库的默认样式。

## 路由分组

| 分组       | 路由                                                                                                                                                                     | 迁移顺序                                         |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------ |
| 公开展示   | `/`、`/prompts`、`/share`、`/pricing`、`/updates`、`/app-space`、`/auth`、`/access-limited`、404                                                                         | 第一批，从静态和低状态页面开始                   |
| 本地工具   | `/tools/puzzle`、`/tools/image-compress`                                                                                                                                 | 第二批，保持本地文件处理结果一致                 |
| 账户与活动 | `/history`、`/feedback`、`/check-in`、`/incentive-plans/**`、`/profile`、`/submissions`、`/wallet`、`/account`、`/notifications`、`/materials`                           | 第三批，固定鉴权、空态、正常态和异常态           |
| AI 工作台  | `/studio`、`/text-to-image`、`/assistant`、`/ecommerce-design`、`/ai-illustration-coloring`、`/tools/background-remove`、`/design-workshop`、`/model-sheet`、`/game-art` | 第四批，逐项验证任务、积分、上传、轮询和结果恢复 |
| 智能画布   | `/canvas`                                                                                                                                                                | 最后原生接入现有 React 画布并移除 iframe         |

`/ai-wallpaper`、`/ai-puzzle`、`/auth/login`、`/auth/register` 和 `/incentive-plans/milestone` 是兼容重定向，切换时必须保留。
