商品图一键生产工作流

导入方法：
1. 打开 http://127.0.0.1:3105/canvas
2. 进入“我的画布”页面。
3. 点击“导入画布”，选择 ecommerce-product-production-workflow.zip。
4. 打开导入后的“模板｜商品图一键生产：透明底 → 白底主图 → 场景视觉”。

使用方法：
1. 选中“01｜替换成你的商品原图”图片节点。
2. 点击图片节点工具栏中的“替换图片”，上传商品图。
3. 根据需要调整三个生成配置节点的模型、尺寸、数量和提示词。
4. 点击右上角“运行工作流”，统一确认一次积分费用。
5. 工作流会依次更新透明 PNG、白底主图和场景主视觉输出节点。
6. 下次换商品时只替换第一个图片节点，然后再次运行。

说明：
- 工作流仅使用图片节点和生成配置节点，不含视频或音频。
- 三个输出节点是稳定输出槽，重复运行不会持续新增节点。
- 默认生成 1 张透明母资产、3 张白底主图和 3 张场景主视觉。
- 默认模型为 gpt-image-2；若账号没有该模型，请在配置节点中选择可用图片模型。
- 透明背景步骤可能包含额外的背景移除积分费用。
